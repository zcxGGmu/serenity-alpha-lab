# Quant Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a DSA Web Quant Lab extension that consumes `/api/v1/quant/backtest-runs` for formal portfolio backtest creation, status, results, artifacts and cancellation.

**Architecture:** Follow the `SAL-P3-015` Screen Lab patch pattern: edit the isolated DSA worktree, generate a new `DSA-PATCH-006`, and keep Serenity root source authoritative for application contracts. The UI is a client-only contract surface over the framework-neutral formal backtest API and must not start Worker/Qlib/Provider/LLM runtime or rename legacy Signal Evaluation.

**Tech Stack:** React 19, TypeScript, Vite/Vitest, Testing Library, lucide-react, DSA common components, Serenity docs/checklist evidence.
