# Auth RBAC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement `SAL-P6-001` by freezing the desktop/standalone/team identity model, RBAC permission matrix, optional OIDC mapping contract, and API authorization requirements without enabling runtime Provider/LLM/Worker/Qlib/sender paths.

**Architecture:** Add a framework-neutral application module `src/serenity_alpha_lab/application/auth_rbac.py` that owns immutable identity, role, permission, profile and route-requirement DTOs plus a deterministic `RbacPolicy`. Desktop mode keeps local usability by granting a local owner/admin subject without requiring OIDC; team mode separates data, run, config and administration duties through explicit roles and permissions. OIDC support is declaration and claim-mapping only; it never imports an OIDC/JWT SDK or performs network validation in this task.

**Tech Stack:** Python dataclasses/enums, existing ProblemDetails style, pytest contract tests, architecture import guard, Markdown evidence doc.

## Task 2: Green Identity, RBAC And Route Catalog

**Files:**
- Create: `src/serenity_alpha_lab/application/auth_rbac.py`
- Modify: `src/serenity_alpha_lab/application/__init__.py`

- [ ] **Step 1: Implement immutable auth DTOs**

Define contract constants and enums:

```python
AUTH_RBAC_CONTRACT_VERSION = "security.auth_rbac@1.0.0"
AUTH_RBAC_SCHEMA_NAME = "security.auth_rbac_policy"
AUTH_RBAC_SCHEMA_VERSION = "1.0.0"

class AuthMode(StrEnum):
    DESKTOP = "desktop"
    STANDALONE = "standalone"
    TEAM = "team"
```

Add roles for local owner, admin, config admin, data steward, run operator, researcher, viewer, auditor and service worker. Add permissions that separate data read/write, run create/read/cancel, definition read/write, evidence/report read/write, artifact download, config read/write, user admin, audit read and service execution.

- [ ] **Step 2: Implement policy checks**

`RbacPolicy.default(mode)` must provide mode-specific role matrices:

- desktop: `LOCAL_OWNER` grants all current permissions and does not require OIDC.
- standalone: local admin/researcher/viewer roles exist; admin can configure and manage users, researcher can create runs and reports, viewer is read-only.
- team: data, run, config and administration permissions are separated; no single non-admin role can perform all four domains.

`policy.authorize(subject, permission, resource)` returns a deterministic `AuthorizationDecision` with allow/deny, issue code and matched roles. Tenant/team mismatches deny by default. Service workers are allowed only for service execution and run read/update style permissions required by future worker adapters.

- [ ] **Step 3: Implement OIDC declaration and claim mapping**

`OidcProviderConfig` must validate issuer/client/audience strings and expose redacted `to_record()` with no secrets. `OidcClaimMapping.map_claims()` maps pre-validated claims into `AuthSubject` using configured role/group/team claim names and deny-by-default unknown role aliases. It must not verify tokens, fetch JWKs or call a network.

- [ ] **Step 4: Implement API authorization catalog**

`default_api_authorization_catalog()` must return deterministic route requirements for:

- config/auth/user administration,
- dataset/evidence/report reads and writes,
- screening and formal backtest run create/read/cancel,
- artifact downloads,
- notification outbox read/admin metadata.

Every route must declare HTTP method, path template, resource kind and at least one required permission. The catalog must avoid legacy formal-backtest promotion or sender/runtime semantics.

- [ ] **Step 5: Export public symbols**

Add RBAC public symbols to `src/serenity_alpha_lab/application/__init__.py` without importing runtime frameworks.

- [ ] **Step 6: Run focused Green**

Run:

```bash
uv run --extra core --extra dev python -m pytest tests/application/test_auth_rbac.py -q
```

Expected: all focused tests pass.
