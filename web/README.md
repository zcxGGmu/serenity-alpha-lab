# Serenity Alpha Lab Homepage

This directory is the GitHub Pages source for Serenity Alpha Lab.

- Public URL: `https://zcxggmu.github.io/serenity-alpha-lab/`
- Local preview: open `web/index.html` directly in a browser.
- Publishing: `.github/workflows/deploy-pages.yml` uploads this directory as a static Pages artifact on pushes to `main`.

The site is intentionally static: no build step, analytics, external scripts, Provider runtime, LLM runtime, Worker loop, Qlib runtime, production scheduler, notification sender, release packaging or formal portfolio backtest promotion.
